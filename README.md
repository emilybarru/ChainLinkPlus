# ChainLinkPlus

Connects various cryptocurrency exchanges to a centralized platform for real-time data aggregation and analytics.

The key benefits of using ChainLinkPlus include:

- Connects various cryptocurrency exchanges to
- a centralized platform for real-time
- data aggregation and analytics

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainLinkPlus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure ChainLinkPlus, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
